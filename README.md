# Yukiri

现代、简约的 C++23 保留模式 GUI 静态库。首版目标是 Windows 10 22H2 / Windows 11 x64，使用 SDL3 与 Vulkan 1.4，支持 MSVC、MinGW、CMake 和 Ninja。

项目正在按里程碑实现，实际完成情况以 [项目状态](docs/Status.md) 和 [验证记录](docs/Validation.md) 为准。
