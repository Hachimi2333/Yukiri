# 文字

0.2 的 TextBox / TextArea 共用 TextEditor、TextComposition、TextVisual 与 DocumentLayout。多行保留 Tab 并把 CRLF / CR 规范化为 LF，显示时 Tab 展为四列制表位；密码按字素显示掩码。组合文本始终使用独立显示状态，布局、选区、命中及候选区域从同一份显示数据计算。

DocumentLayout 复用修改前后未变化段落的测量及光标位置，字体、字号、DPI、字体加载版本或换行宽度改变时失效。绘制只枚举当前可见行；滚动不重新测量内容。编辑历史存储文本差分，连续 750ms 内的相邻输入 / 同向删除可合并，导航、组合提交与显式操作分组；最多 128 项、约 16MiB（保留最后一次操作，即使该项较大）。全部替换是一项历史记录。

查找按字面文本进行，匹配两端必须是字素边界。Windows 忽略大小写使用不依赖当前区域的 Unicode 大写映射，保留原 UTF-8 位置，不进行规范化等价或正则处理。密码字段仍允许应用通过 GetText 管理值，但 GetAccessibleText 返回空，Copy / Cut 拒绝读取且不访问系统剪贴板。

0.2 字体描述增加族、字重与斜体；字体文件字节在同一路径的字体面 / 样式之间共享。选择结果和塑形缓存分别区分完整字体描述，注册字体后失效；Windows 系统字体匹配仍在适配层完成。变量字体按轴选择样式，必要时使用 FreeType / HarfBuzz 合成样式。字号和 DPI 继续参与字形 / 塑形区分。

内部 TextLayout 统一显式换行、Unicode 断行、长单词的字素拆分及安全省略号。段落光标位置一次获取，修复原先每个边界从头扫描字形的平方开销；边界与字形簇现在按单向遍历匹配，后续多行编辑复用这条路径。窄 Grid 按分配列宽重新测量文字，避免行高仍使用整个 Grid 的宽度。

公共字符串使用 UTF-8。FreeType 加载与栅格化字形，HarfBuzz 塑形，libunibreak 计算字素、单词和换行边界。Windows 字体发现和系统输入法在平台适配层处理。

首版面向中英文日常使用，完整双向段落和彩色 Emoji 属于后续规划。

Windows 通过 DirectWrite 发现系统字体文件，实际塑形与栅格化使用 HarfBuzz / FreeType。字体按完整字素选择回退，glyph cache 以字体、字号和 glyph ID 为键，按需分配 2048×2048 R8 图集页。字体以文件内容加载，允许非 ASCII 自定义路径。Application::LoadFont 可加载并优先使用自定义字体。

TextBox 的单行模型使用 UTF-8 字节偏移并按字素边界校正。支持选择、单词移动、复制 / 剪切 / 粘贴、128 步撤销历史和只读模式。输入法预编辑单独保存，显示下划线，提交后再替换所选内容；取消不更改已提交文本。候选区域跟随排版后的光标位置。

复杂脚本的完整段落方向分析和彩色 Emoji 尚不属于本版。组合输入自动化测试不替代真实 Windows IME 检查。

字形四边形对齐物理像素；当前图集接受 FreeType 的灰度、单色 bitmap 和 BGRA 的 Alpha 覆盖率，拒绝其他像素格式；BGRA 仅用覆盖率按文字色绘制，不提供彩色 Emoji。

塑形结果使用约 8MiB 的有界 LRU 缓存，区分原始文本、字号和 DPI；成功加载字体时清空缓存，以更新回退链。测量和绘制共享结果，超大条目不驻留。完全位于裁剪区域外的控件子树跳过绘制；包含文本输入焦点的祖先路径保留位置更新，使 IME 区域在滚出视口时仍同步。空裁剪区不生成文字字形绘制。

GPU 平台 smoke 读取 SDL 文本输入区域，检查滚动 200 DIP 后的光标区域位移（包括文本框完全移出裁剪区），避免裁剪优化留下过期候选窗位置。

SDL 初始化前明确声明 composition 由框架显示，候选列表仍为原生 UI。TextComposition 集中生成实际绘制文本、组合下划线范围、选区与光标字节偏移；不自行拼接拼音分隔符。负光标位置视为组合末尾，其他偏移限制在有效字符边界。预编辑不发送 TextChanged；提交替换原选区并进入一次撤销历史，取消、失焦、只读和外部 SetText（即使文本相同）均清理组合。
