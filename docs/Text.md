# 文字

公共字符串使用 UTF-8。FreeType 加载与栅格化字形，HarfBuzz 塑形，libunibreak 计算字素、单词和换行边界。Windows 字体发现和系统输入法在平台适配层处理。

首版面向中英文日常使用，完整双向段落和彩色 Emoji 属于后续规划。

Windows 通过 DirectWrite 发现系统字体文件，实际塑形与栅格化使用 HarfBuzz / FreeType。字体按完整字素选择回退，glyph cache 以字体、字号和 glyph ID 为键，按需分配 2048×2048 R8 图集页。字体以文件内容加载，允许非 ASCII 自定义路径。Application::LoadFont 可加载并优先使用自定义字体。

TextBox 的单行模型使用 UTF-8 字节偏移并按字素边界校正。支持选择、单词移动、复制 / 剪切 / 粘贴、128 步撤销历史和只读模式。输入法预编辑单独保存，显示下划线，提交后再替换所选内容；取消不更改已提交文本。候选区域跟随排版后的光标位置。

复杂脚本的完整段落方向分析和彩色 Emoji 尚不属于本版。组合输入自动化测试不替代真实 Windows IME 检查。

字形四边形对齐物理像素；当前图集接受 FreeType 的灰度、单色 bitmap 和 BGRA 的 Alpha 覆盖率，拒绝其他像素格式；BGRA 仅用覆盖率按文字色绘制，不提供彩色 Emoji。

塑形结果使用约 8MiB 的有界 LRU 缓存，区分原始文本、字号和 DPI；成功加载字体时清空缓存，以更新回退链。测量和绘制共享结果，超大条目不驻留。完全位于裁剪区域外的控件子树跳过绘制。
