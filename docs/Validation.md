## 本机性能量测

相同 FrameBenchmark 源码分别链接优化前 cda83bc 安装包与优化后 MSVC Release 静态库，开启验证层，单轮约 8 秒：

| 场景 / 指标 | 优化前 | 优化后 |
|---|---|---|
| 持续悬停：绘制次数 | 865 | 1902 |
| 持续悬停：预热间隔 p50 / p95 | 7.6791 / 16.687ms | 4.1281 / 4.7088ms |
| 持续悬停：整个进程 CPU 时间 | 2421.875ms | 2187.5ms |
| 连续反向滚轮：绘制次数 | 101 | 1899 |
| 连续反向滚轮：预热间隔 p50 / p95 | 80.0169 / 80.6398ms | 4.1292 / 4.6822ms |
| 连续反向滚轮：预热测量次数 | 176 | 0 |
| 连续反向滚轮：整个进程 CPU 时间 | 1875ms | 4234.375ms |

旧版滚动只在输入事件后跳转；新版在输入之间补充动画帧，因此持续滚动的总 CPU 使用量增加，同时输出约 19 倍绘制帧。优化后的滚动预热 CPU p95 为 0.6033ms；进程 CPU 时间另包含驱动与计时等线程开销。

追加 --settle 在结束前停止滚轮输入，等待动画收稳后记录 idle_frames=0、warm_measure_calls=0。独立 Demo --idle-smoke 约 5.4 秒只提交一帧。空闲不持续重绘。

上述数据是当前机器的局部对比，绘制 / 提交间隔不等于物理显示帧率，也不是所有硬件和应用的性能承诺。
