# 架构

应用 / Demo 使用公开控件、布局、主题与 Canvas；UI 核心处理树、路由与调度；私有平台、文字和渲染服务对接第三方库。公共头文件不暴露第三方或 Win32 类型。

| 目录 | 职责 |
|---|---|
| include/Yukiri | 可安装的公开 API |
| src/Core、src/UI、src/Layout | 基础类型、控件树、输入和布局 |
| src/Controls、src/Styling | 控件行为、样式解析 |
| src/Platform | SDL 生命周期、系统字体发现、Win32 标题栏适配 |
| src/Text | Unicode 边界、编辑模型、字体塑形、字形图集 |
| src/Render | Vulkan 设备、资源、交换链、Canvas 绘制列表 |
| demo、tests、tools、cmake | 展示、验证、脚本和构建 / 安装元数据 |

Application 拥有窗口，窗口拥有根控件，父控件以 unique_ptr 独占拥有子控件。控件地址稳定且不可复制 / 移动；返回的指针与引用只用于观察。主线程负责 UI、文字和渲染调度，GPU 异步执行命令。多个窗口共享设备与文字服务，各自保存交换链、帧资源、焦点、指针捕获和弹出层。

输入、测量 / 排列、绘制和直接焦点回调均处于树的分发保护范围。回调期间的移除或根替换延迟到最外层操作结束；容器遍历使用子控件指针快照，允许回调添加子控件。自定义容器应使用受保护的 Children() 快照遍历，不在遍历过程中持有 GetChildren() 的迭代器。

布局和绘制使用独立失效标记。窗口在调用布局 / 绘制前消费当前标记，因此回调中新产生的失效保留到下一轮。无动画且无失效时等待 SDL 事件；文本焦点的光标按 500ms 节奏更新。最小化不提交渲染，交换链需要重试时安排下一帧。

关闭先标记，Poll 在安全边界发出 m_Closed，再释放窗口。Poll 禁止重入并返回错误；关闭回调可创建其他窗口、关闭其他窗口或清空观察指针，但不可递归驱动消息循环。Application 析构时直接清理资源，不发送关闭通知。

自绘标题栏通过独立 Windows subclass 实现，Canvas 绘制标题与按钮。标题栏和内容区域分别布局，缩放边缘、拖动区和按钮分别命中；最大化按钮返回 HTMAXBUTTON。原生窗口仍由系统提供标题栏。Linux 尚未提供平台构建和验证承诺。
