# 架构

依赖方向：应用 / Demo → 控件、布局与主题 → UI 核心、Canvas 和文字服务 → 平台适配与 Vulkan 渲染 → 固定版本第三方依赖。

窗口由 Application 管理，窗口拥有根控件，父控件以 unique_ptr 独占拥有子控件。引用只用于观察；控件不可复制或移动。主线程负责 UI 更新、事件处理和渲染调度，GPU 异步执行提交的命令。

多个窗口共享图形设备，但各自保存交换链、帧资源、焦点、指针捕获和弹出层。平台接口不把 SDL 或 Win32 类型传播到公共 API。

采用测量、排列、绘制失效标记和按需事件等待。输入处理期间的移除与关闭在安全边界完成，避免回调栈上的对象被立即释放。
