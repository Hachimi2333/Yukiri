# 用户启动的桌面验收

本轮开发不使用 Computer Use，不代替用户操作桌面。以下检查由用户有空时启动。
未执行的项目保持待验收，编译与 CPU 测试不替代真实体验。

## 运行和日志

使用 `tools/Build.ps1 -Preset msvc-release -Test` 构建后，运行 `out/build/msvc-release/YukiriDemo.exe`。
GPU 检查可自行运行 `tools/GpuSmoke.ps1 -Preset msvc-release`，日志写入 out 下对应 preset 的 stdout / stderr 文件。
也可用 MinGW 对应 preset 验证；本轮自动工作不启动这些 GPU 程序。

## 应用、输入与窗口

- [ ] 原生 / 自绘窗口的点击、双击、拖动和系统按钮正常。
- [ ] Tab / Shift+Tab 显示焦点框，鼠标点击隐藏焦点框。
- [ ] 按住 Space 时按钮显示按下，释放激活一次；切到其他应用再释放不误激活。
- [ ] 拖动滑块或滚动条时切到其他应用，回来后没有残留拖动状态。
- [ ] 中英文编辑、AltGr 输入和应用快捷键互不抢占。
- [ ] 文件拖入程序后得到正确的一批 Unicode 路径。
- [ ] 可取消关闭、所属窗口、Show / Hide / Activate 在实际应用流程中行为正常。

## 字体与布局

- [ ] 默认、指定字体族、粗体和斜体的中英文显示正常，测量与光标位置匹配。
- [ ] 窄窗口文字换行、省略号、对齐和内边距正常。
- [ ] WrapPanel 随窗口改变宽度正确换行，SplitPanel 的拖动、方向键、Shift 精细调整及最小尺寸正常。
- [ ] 操作分割条时切换应用，不残留拖动或错误光标。

## 图片与图形资源

- [ ] PNG / JPEG / BMP / ICO 和静态 SVG 显示正确，半透明边缘在浅深背景下没有暗边。
- [ ] ImageView 的四种缩放模式、裁剪及绘制透明度符合预期。
- [ ] 反复切换图片、关闭窗口后资源使用趋于稳定；同时可用超过 512 张纹理。
- [ ] DPI 改变后 SVG 清晰，原生 / 自绘标题栏图标仍正确。
- [ ] GPU smoke 的验证日志没有新增 Vulkan 错误；本轮尚未自动执行。

## 菜单与对话框

- [ ] 浅深主题的菜单图标、勾选、禁用、快捷键及分隔线清晰；高菜单可滚动。
- [ ] F10 / Alt+助记键、方向键、Home / End、Enter / Space、Escape 逐层退出，右键 / 菜单键 / Shift+F10 正常。
- [ ] 快速切换菜单、关闭子菜单或销毁所属控件，不留下不可见的输入层；窗口大小变化后菜单定位正确。
- [ ] 工具提示延迟出现且不抢焦点；点击、滚动、失焦后消失。
- [ ] 模态对话框限制 Tab 与外部命令，默认 / 取消按钮正常，完成后恢复仍存在的原焦点；IME Escape 优先取消组合。
- [ ] 打开 / 保存 / 选目录界面支持 Unicode 路径、多选、过滤器、默认路径，取消不当作错误。
- [ ] 文件对话框未结束时关闭所属窗口或退出应用，不留下窗口或后台任务；取消后可以再次打开。

## 多行编辑与输入

- [ ] TextArea 中中英文多行、自动换行 / 横向滚动、跨行选择与上下 / Home / End / PageUp / PageDown 正常。
- [ ] 双击选词、三击选行、越界拖动自动滚动，反向滚轮平滑，改变大小后滚动范围正确。
- [ ] 多行预编辑下划线、组合选区及候选窗跟随光标；滚动、取消、提交、失焦和只读切换不重复提交。
- [ ] 剪贴板复制 / 剪切 / 粘贴正确，撤销合并自然，全部替换只需一次撤销；字素不被截断。
- [ ] 密码字段只显示掩码，Ctrl+C / Ctrl+X 不改变剪贴板，无障碍不读出明文。
- [ ] NumberBox 有效输入可提交，无效 / 越界保持原值并有反馈；步进与格式符合设置。
- [ ] 单选组、ComboBox、Slider 的键盘操作及不确定进度动画符合 API 说明；关闭动效后没有持续调度。

## 数据管理

- [ ] 列表、树与表格共享模型，选择变化可同步；插入 / 排序后仍选中同一数据，删除后无失效项。
- [ ] Ctrl / Shift 多选、Ctrl+A、方向键、Home / End / PageUp / PageDown 和滚动进入视口正常。
- [ ] 树的折叠 / 展开、滚入深层子项、隐藏选区和当前行行为正常。
- [ ] 表头点击排序、拖动列宽、当前列移动、水平 / 垂直滚动及滚动条直接拖动正常。
- [ ] F2 / 双击文本编辑、Enter 提交、Escape 取消、失焦提交及无效内容反馈正确；勾选可操作。
- [ ] 十万行持续滚动无明显停顿，窗口 / 数据反复销毁不持续积累控件和图片资源。

无障碍检查会随对应阶段交付补充。

## 0.2 Windows 无障碍（用户启动，尚未执行）

1. 启动 Demo 与 Windows Narrator / Inspect，分别打开自绘和原生窗口；检查名称、角色、状态及物理屏幕边界。Tab 导航时应朗读当前控件，鼠标仍按原焦点框规则工作。
2. 操作按钮、开关、单选组、滑块、数值输入、Tab、下拉层和菜单；检查对应 Invoke / Toggle / Selection / ExpandCollapse / RangeValue。模态出现时底层不可操作，关闭后焦点恢复。
3. 在 TextArea 中输入中英文、跨行选择、查找、撤销、滚动；检查文字范围与可见范围。密码字段不得朗读或通过 Value / Text 取到明文。
4. 在十万行数据中导航、展开、排序和编辑；检查 Grid / Table、当前行、列标题、Realize，确认没有逐行 Widget。删除模型项或关闭窗口后旧元素应不可用。
5. 检查自绘系统按钮名称与操作，取消文档关闭后窗口仍存在。跨 DPI 移动后 Inspect 边界应跟随。
6. 记录 Windows / Narrator 版本、工具链、装饰模式、DPI、复现步骤及日志。此清单未执行，不记为通过。

## 0.2 Demo 文档流程（用户启动，尚未执行）

1. 运行 `YukiriDemo.exe --editor`，输入中英文多行，检查换行、选区、IME 组合与候选窗；用 Ctrl+F 查找及全部替换，再撤销一次，确认整次替换被恢复。
2. Ctrl+S 选择中文路径保存，关闭后重新打开，检查文本一致。新建 / 打开 / 关闭有未保存更改时，分别选保存、放弃、取消；取消文件选择或错误路径不能清空文档。
3. 保存时继续编辑，确认写入完成后新编辑仍标为未保存；关闭再次确认。测试 UTF-8 BOM / CRLF 文件，以及 UTF-16 / 二进制拒绝反馈。
4. 检查菜单、工具栏和快捷键共享启用状态、右键、自动换行、主题切换；把文本文件拖入窗口，确认先询问未保存更改。

## 0.2 Demo 数据流程（用户启动，尚未执行）

1. 运行 `YukiriDemo.exe --data`，对比三个视图的共享选择和编辑；展开示例子项，修改勾选、名称、状态和备注，排序后选择仍按稳定 ID 保留。
2. Ctrl / Shift 多选后删除；添加新记录、Enter 提交、Escape 取消、F2 编辑，拖动列边与两个分割条。
3. 输入 100000 行后 Ctrl+L，检查进度、交互响应和滚动；加载中取消，已加载行保留。立即重新加载或关闭窗口，检查无迟到回调崩溃。
4. 交替运行原生 / 自绘窗口和浅 / 深主题，检查窄窗口工具栏换行、焦点、图像、字体和文字清晰度。
5. 使用 GPU 验证层及 Narrator 复验，并在 Validation 记录实际结果；本轮自动检查不执行以上步骤。
